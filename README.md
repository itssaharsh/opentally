# OpenTally

Mini-grid grants in Nigeria wait on four private tallies. OpenTally releases each connection's grant on one public rule anyone can re-sum.

Built for the IEEE ClimateChain Global Hackathon 2026 (Devpost). Planning started on 19 October 2026 from a research package kept outside this repository; the first commit is dated after that.

- `contracts/`: Hardhat 3, Solidity, viem. The programme contract (escrow, sites, connections, EIP-712 summaries, rule, holds, release), a factory and a test token.
- `web/`: Next.js 16 on Vercel. The tally, the run pipeline, the connection view, the rule page and the re-sum.
- `docs/`: the deliverables.

Live link, video and the rest of the first screen follow as they exist.
